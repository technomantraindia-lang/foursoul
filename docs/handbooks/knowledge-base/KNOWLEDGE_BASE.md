# FourSouls Deterministic Knowledge Base

Entries are indexed by stable ID, audience, category, keywords, aliases, question variants, and document section. A future help screen can match normalized user text to these records without AI or external services.

## KB-COURSE-001

**Title:** Create and publish a course  
**Category:** Courses  
**Audience:** Admin  
**Keywords:** course, create, publish, pricing, catalogue  
**Aliases:** class, program, new course  
**Questions:** How do I add a course?; How do I publish a course?; Why is my course not visible?  
**Answer:** Create the course, add sections and lessons, set independent prices, then publish.  
**Full documentation:** `../admin/ADMIN_HANDBOOK.md`  
**Related:** KB-LESSON-001, KB-ACCESS-001

## KB-PAYMENT-001

**Title:** Payment pending  
**Category:** Payments  
**Audience:** Admin, Customer  
**Keywords:** payment, pending, order, provider, UAE  
**Questions:** Why is payment pending?; Is card payment live?
