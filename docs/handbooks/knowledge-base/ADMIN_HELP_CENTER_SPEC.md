# Admin Help Center Specification

Future location: `Admin -> Help Center`.

The screen should contain a search field labelled **Ask a question or search help**, category shortcuts for Users, Courses, Lessons, Subscriptions, Live Sessions, Payments, Assessments, Certificates, and Troubleshooting, and a result area with title, short answer, steps, related documentation, and related problems.

Search reads `QUESTION_INDEX.json` and ranks deterministic matches. It must not call AI or external services.
